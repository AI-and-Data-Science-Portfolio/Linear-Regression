# Linear-Regression

This repository contains two assignments and a final project. The aim of each was to practice linear regression methods. 

Description:

Assignment 1 - polynomial transformations.

Assignment 2 - dummy variables, interaction terms, further transformations and multicollinearity.

Final Project - logistic regression.

Outputs:

All charts, summaries, tables, etc. can be viewed in [Assignment 1](docs/Assignment%201.pdf), [Assignment 2](docs/Assignment%202.pdf) and [Final Project](docs/Final%20Project.pdf).

How to Run:
1. Download or clone this repository to your computer.
2. Open RStudio and install the required packages:
   ```r
   install.packages(c("ggplot2", "dplyr", "lmtest", "MASS", "openxlsx", "knitr", "pscl", "car"))
   ```
4. Open [`src/LR Assignment 1.R`](src/LR%20Assignment%201.R), [`src/LR Assignment 2.R`](src/LR%20Assignment%202.R), or [`src/LR Final Project.R`](src/LR%20Final%20Project.R) and run the chosen script from top to bottom.
